# Update 2026-05-11 — Manual Quota Counter

## Vấn đề

Nhiều provider (AliCode, OpenCode Free, Kiro...) không có quota API để 9Router tự động lấy hạn mức sử dụng. Kết quả: trang Provider Limits hiển thị "Plan auto-detection unavailable" hoặc "Usage not available".

## Giải pháp

Xây dựng bộ đếm request thủ công bằng local SQLite — đếm số request thực tế từ `usageDaily` table, so sánh với thresholds để tự động detect plan.

## AliCode quota plans

| Window | Lite | Pro |
|--------|------|-----|
| 5h requests | 1,200 | 6,000 |
| Weekly requests | 9,000 | 45,000 |
| Monthly requests | 18,000 | 90,000 |

**Logic detect plan:**
- Monthly requests < 18,000 → **Lite**
- Monthly requests >= 18,000 → **Pro**

## Kiến trúc

### File mới: `src/lib/db/repos/manualQuotaRepo.js`

```
manualQuotaRepo.js
├── ALICODE_PLANS          # Định nghĩa thresholds Lite/Pro
├── detectAlicodePlan()    # Auto-detect plan từ monthly count
├── countRequestsInWindow() # Đếm request từ usageDaily
├── getAlicodeManualQuota() # Hàm chính, trả về quota array
├── hasManualQuota()       # Registry check
└── getManualQuota()       # Registry lookup
```

**Registry pattern** — dễ thêm provider mới:

```js
const MANUAL_QUOTA_HANDLERS = {
  alicode: getAlicodeManualQuota,
  "alicode-intl": getAlicodeManualQuota,
  // Thêm provider mới ở đây
};
```

### Sửa: `src/app/api/usage/[connectionId]/route.js`

Ưu tiên manual quota check TRƯỚC khi gọi provider API thật:

```js
// Manual quota first
if (hasManualQuota(connection.provider)) {
  const manualQuota = await getManualQuota(connection.provider, connectionId);
  return Response.json(manualQuota);
}
// ... existing provider API flow
```

### Sửa: `src/app/(dashboard)/dashboard/usage/components/ProviderLimits/utils.js`

Thêm case `alicode` và `alicode-intl` vào `parseQuotaData()` để parse manual quota array.

### Sửa: `src/app/(dashboard)/dashboard/usage/components/ProviderLimits/index.js`

- Badge `[Local]` (xanh) khi quota từ manual counter
- Badge plan name (tím: "Lite" hoặc "Pro")
